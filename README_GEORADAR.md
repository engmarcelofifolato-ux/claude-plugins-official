# 🚀 GeoRadar Agro v1.0

## Inteligência Territorial para o Agronegócio

Uma plataforma moderna de busca e qualificação de leads para o setor agrícola. Monitora eventos fundiários, ambientais e empresariais em tempo real, entregando leads qualificados com timing perfeito.

---

## ✨ Principais Características

### 🎯 Landing Page Completa
- Hero section com animação de radar em tempo real
- Seção "Como Funciona" com 3 pilares principais
- **Planos e Preços** com 3 tiers competitivos:
  - **Básico**: R$ 499/mês (2 módulos, 5K leads/mês)
  - **Profissional**: R$ 1.299/mês (4 módulos, 50K leads/mês) ⭐
  - **Premium**: R$ 2.999/mês (5 módulos, ilimitado)
- Formulário de cadastro com seleção de módulos
- Footer com navegação e links úteis

### 📊 Plataforma de Busca Avançada

#### 5 Módulos Especializados
- **🗺️ Fundiário**: SIGEF, CAR, Matrículas, Remembramentos
- **💰 Crédito Rural**: Expansão, CNPJ novo, Financiamentos
- **🌱 Ambiental**: CAR, Licenças, Regularizações
- **☀️ Solar Rural**: Consumo, Tarifas, Pivôs, Potencial solar
- **🏢 Empresas**: CNPJ, Alterações societárias, Capital

#### Dashboard com Dupla Visualização
- **Visualização Linhas**: Tabela estruturada com 6 colunas
- **Visualização Quadros**: Grid de cards com resumo visual
- **Toggle instantâneo** entre visualizações

#### Filtros Avançados
- Status (Novo, Contactado, Fechado)
- Score (Quente 80-100, Morno 60-79, Frio <60)
- Busca textual em tempo real por nome, localização, proprietário

#### Modal de Detalhes Completo
- Score e Status com badges coloridas
- Informações comerciais (CNPJ, Proprietário, Área, Atividade)
- Eventos associados (tags dinâmicas)
- Serviços recomendados
- Público-alvo especializado
- Ações: Marcar como Contactado/Fechado

### 📤 Exportação e Integração
- **CSV Export**: Dashboard completo com todos os visíveis
- **CSV Individual**: Lead específico com detalhes completos
- **WhatsApp**: Compartilhamento com mensagem pré-preenchida
- Formatação automática de dados

### ⚡ Performance em Larga Escala
- **40.000+ leads** testados (10K por módulo)
- **1.1 MILHÕES de leads/segundo** de performance
- Geração de dados em apenas **34ms**
- Consumo de memória: ~98 MB
- Distribuição realista de scores

## 🛠️ Tecnologia

### Frontend Stack
- **HTML5** + **CSS3** com CSS Variables
- **JavaScript Vanilla** (sem frameworks para máxima performance)
- **React 18 via CDN** (opcional para extensões futuras)
- **Babel Standalone** para JSX transpilation
- **Google Fonts**: Bebas Neue, Syne, DM Sans

### Características Técnicas
- **Single-file SPA** (~50 KB minificado)
- **Sem build process** necessário
- **100% standalone** - funciona em qualquer navegador moderno
- **Responsive design** (mobile, tablet, desktop)
- **Carregamento instantâneo**

### Design System
- Paleta de cores harmônica (verde natural, terras, dourados)
- Ícones emoji para naturalidade
- Tipografia profissional e clara
- Bordas e espaçamentos consistentes
- Animações suaves

## 📥 Como Usar

### 1. Acesso Rápido
```
Abra o arquivo: index-nova.html
No navegador (Chrome, Firefox, Safari, Edge)
```

### 2. Landing Page
- Explore os planos e preços
- Conheça o produto
- Preencha o formulário de cadastro
- Clique em "Acessar Plataforma"

### 3. Dashboard
- Selecione um módulo
- Use os filtros para encontrar leads
- Alterne entre visualizações (Linhas/Quadros)
- Clique em um lead para ver detalhes
- Exporte ou compartilhe via WhatsApp

### 4. Ações com Leads
- **Marcar como Contactado**: Registra interação
- **Marcar como Fechado**: Indica conclusão
- **Exportar**: Baixa dados em CSV
- **WhatsApp**: Abre chat com mensagem pré-preenchida
